# The Corner Table: demo preview

A read-only, fully generic demo of a restaurant website and its admin panel, filled with sample data: 14 menu categories and 84 dishes (each with its own photo), events, blog posts, team, offers, FAQs, bookings, queue, orders, guests, loyalty, partners, inbox and more.

- Website: the site root
- Admin panel: `/admin` (read-only; nothing is saved)

Every name, phone number, email and address is made up. Photographs come from Wikimedia Commons under their own licences, listed in [PHOTO-CREDITS.md](PHOTO-CREDITS.md). Not a live restaurant.
